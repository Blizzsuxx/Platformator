# Local dependency patches

- SDL3_mixer 3.2.4, `src/decoder_wav.c`: restored the local signed 24-bit WAV conversion patch from 3.2.0. It multiplies the signed high byte by 65536 instead of left-shifting a negative integer. The product fits in Sint32 for every signed high byte, preserving the intended decoded value and sample range without undefined shifting. The 3.2.4 import had replaced this patch and reproduced the UBSan diagnostic; this local integration change restores it. See docs/SDL_UPDATE_VALIDATION.md for validation before and after restoration.
- The TSan preset keeps oneTBB compiler warnings visible but disables its warnings-as-errors option. GCC 16 warns that `atomic_thread_fence` cannot be modeled by TSan; engine and TBB remain instrumented, and runtime race reports are not suppressed.
