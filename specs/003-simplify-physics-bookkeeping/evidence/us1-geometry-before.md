# Geometry characterization and extraction decision

Existing geometry host and regression suite pass on current and baseline runtime (us1-current-characterization.txt and us1-baseline-characterization.txt). Coverage includes circle closest-point/distance and SAT/clipping gaps, exact feature IDs, warm_start_feature_reuse, clip_segment_feature_propagation, support and reference swaps. No duplicate test suite is needed for a mechanical boundary change.

Inspection discovered calculateContactPoint is called only once: the box/box tail of updateContactGeometry. Circle/circle and circle/box dispatch both return before that call and construct their own manifolds. The generic helper retains unreachable circle branches, one reading private GameObject::worldPosition. Moving that dead branch to a free function would require an otherwise unnecessary accessor/friend or a different position computation. Instead remove the unreachable branches and name the remaining helper calculateBoxContactPoints; preserve all reachable shape math/operation order. This is a scope-consistent simplification, not a changed collision algorithm or public API. Compare normalized reachable baseline bodies and run independent shape/warm-start/physical guards.

The original complete geometry source remains under bin/physics-bookkeeping-20261025/baseline-source/src/physicsgeometry.cpp. The extraction comparison must explicitly account for the proven-unreachable branch removal rather than claim token identity of deleted code.

The first extraction compile exposed a second private dependency: Collision::generateFallbackContactPoint, used only by the two clipping-failure branches. Its unchanged midpoint/feature/setContactPoints logic moves into the private geometry implementation using existing public reference/incident getters. The unused private declaration/definition is removed from Collision; no public API or field layout changes. The reachable-token comparison also covers this moved fallback. Original compile diagnostic remains in us1-final-tests.txt; retry results are separate.
