# Broad-phase invariants

Reviewed `paper/paper.txt` §§3.1–3.3 and the current Grid/AABB/segmented implementation. Subdivision puts a collider in every overlapping cell; cell deltas are consolidated by canonical collider identity and witness count so only the first witness publishes a pair and only the last removes it. Endpoint ordering, per-proxy chunk indices, primary-axis checkpoints, fast-crossing cancellation and split/merge preserve interval coverage. The pending pair batch owns no pair; workers write distinct pair-owned results, and serial reduction, event dispatch and erasure follow worker completion. Candidate overlap is separate from confirmed contact and gameplay events. These are invariants to preserve, not a claim that the paper’s historical timings or tuning hold here.
