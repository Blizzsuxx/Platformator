# Matched Release timing captures

`captures.tar.xzdata` holds the 68-job alternating baseline/candidate schedule, schema-3 manifests, summary CSVs and raw samples. Each workload/population/worker cell used five independent processes, 120 warmup steps, 600 measured steps, seed 0 and dt 1/120, with one-worker CPU 0 or six-worker CPUs 0,2,4,6,8,10. `comparison.csv` is generated by `../analyze_timings.py`; each p95 value is the mean of the five per-process p95 values, and standard deviation is across per-process averages. Nested scopes overlap and must not be summed.

`persistent-confirm.tar.xzdata` contains a separate 20-process interleaved follow-up for 1,000 persistent pairs and two scripted endpoints; it investigates variation, not the primary aggregate. An initial attempt to run one repetition through the sweep was rejected by its five-repetition guard; a subsequently tried zero-scripted-endpoint control was a different workload and is not used in the comparison. Direct runner captures with two endpoints are retained here.

The original temporary baseline disappeared between turns. The reconstructed baseline and its independently compared invariant snapshots are described in `../baseline.md` and `../invariants/`; the lost full source manifest cannot be reverified.
