# Asset, debug and compatibility dispositions

C13 removes only the unused resolved-path copy of the request; raw input remains used in validation, diagnostics and warning keys. C14 removes six uncalled direct drawing helpers; supported buffered overlays remain. The migration guide covers the C02 GameObject layout, C03 public field, C04 Audio accessors/layout and C12 public rebinding methods described in the compatibility contract. Consumer verification remains separate.
