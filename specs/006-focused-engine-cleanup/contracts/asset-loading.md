# Asset Loading Contract

Applies to nonempty texture, audio and animation requests from public Runtime, path-based components, scene and active resolvers, behavior references and nested animation frames.

1. First request validates `assets/...` syntax, rejects absolute or traversal paths, resolves against the configured runtime root, rejects symlink escapes, checks the requested regular file, and loads/decodes it. Failure throws with the original request in the message and never substitutes a fallback. Nested failures retain useful context and the offending request. Existing empty/unset paths remain unset where previously supported.
2. Successful requests identify a resource by type and canonical asset path. Previously validated equivalent spellings resolve to the same retained resource. Once a particular raw request has succeeded, repeating that exact request while its resource remains cached returns that resource without filesystem resolution or revalidation, even after deletion/replacement or symlink change. An unseen spelling, even one that used to be equivalent, is validated independently.
3. A request alias is visible only after successful resource association; no failed load or aborted scene transaction may leave a stale alias. Loaded resources follow existing reference and scene-acquisition rules. When the resource is evicted, all of its aliases must be removed before its memory is reclaimed. Cache teardown must make aliases unusable. A subsequent request revalidates against current filesystem state. Tests must include multiple aliases and release/rollback/recreation boundaries.
4. Explicit requests for files formerly used as fallback are allowed like any other valid files. No default fallback selection or fallback warning remains. Document the change for runtime callers and components that previously received defaults.
5. Actual filesystem changes and missing-file behavior are intentional differences from baseline. Measure filesystem calls separately from timing and compare resource ownership/scene outcomes, not obsolete fallback results.
