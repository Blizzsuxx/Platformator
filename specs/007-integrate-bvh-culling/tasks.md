**Input**: Design artifacts in `specs/007-integrate-bvh-culling/`: [spec](spec.md), [plan](plan.md), [research](research.md), [data model](data-model.md), [contracts](contracts/runtime-selection.md), and [quickstart](quickstart.md).

**Scope**: C++20 runtime/SDK, C17 private Box2D tree, existing oneTBB scheduling, SDL3 rendering and Python benchmark tooling. Feature directory `007-integrate-bvh-culling` is independent of current checkout `001-cpp-engine-cleanup`. No new dependency, solver, automatic backend selection, hot switching or default replacement.

**Tests**: Explicitly required by FR-015–017 and SC-002–004/008. Write the listed contract/oracle/regression tests before their corresponding production change, demonstrate the new assertion fails for the intended reason, then make it pass. A build failure from an unimplemented interface alone is not correctness evidence. Preserve existing applicable tests. Record unavailable hardware/sanitizer checks accurately.

Evidence directories/files below are implementation outputs, not claims that captures already exist. Register each new test when its file is added, using `spatial` plus `physics`, `rendering` or `benchmark` labels as appropriate.
