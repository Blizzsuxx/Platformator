Status: in progress. T134's failure-first coverage and T141's portable automated acceptance lane are recorded below. Native accessibility-provider and cross-platform desktop acceptance remain open under their own tasks.

## T135 asset-document foundation

`AssetDocument` loads JSON object roots independently of the scene-array parser, retains unknown members, source path and native file identity, and tracks history/saved tokens. Set/remove operations store path-addressed before/after values; Undo/Redo preserve unrelated content and support exact array append/removal restoration. Save uses the native atomic writer, verifies the observed destination identity, reports conflicts without clearing dirty state, and requires an explicit overwrite decision for an existing Save As destination.

Focused command:

```sh
cmake --build build --target platformator_editor_assetdocument_test platformator_editor -j8
ctest --test-dir build -R '^platformator_editor_assetdocument_test$' --output-on-failure
git diff --check
```

Outcome: build passed and the asset-document regression passed 1/1. Coverage includes unknown top-level/frame members, nested path Undo/Redo, array append/removal restoration, invalid pointers, save/reopen, source-change conflict preservation, Save As no-overwrite/explicit-overwrite behavior, and rejection of scene-array roots. No animation UI or cross-platform verification was performed.

## T136 shared frame timing and validation

Added one engine timing resolver used by `Animator`, engine animation serialization, and editor clip validation: “Positive duration overrides FPS; zero means the existing FPS fallback.” Negative/nonfinite durations and invalid fallback FPS are rejected. The serializer validates timing before mutating or writing a clip, while the editor validator reports JSON-pointer locations and leaves unknown members accepted.

Outcome: build passed and all four focused tests passed. Timing coverage includes explicit-duration override, zero/FPS fallback, invalid duration/FPS rejection, unknown-field acceptance, and engine round-trip compatibility. Visual authoring and full animation acceptance remain open.

## Animation preview refresh (T140)

- Added one bounded animation preview projection shared by saved-file preparation and live `AssetDocument` drafts. Preview projection rejects descriptions above the 1 MiB projected-data budget or 512 frames without truncating or changing the authored JSON; frame timing uses the same positive-duration/zero-FPS fallback resolver as the editor and runtime.
- The Project panel receives the active asset tab's current history/saved-token version and uses it for the asset tile preview. Edits, Undo/Redo, and saves replace only that asset preview; watcher invalidations reapply the current draft, while texture changes invalidate only dependent thumbnails/animation previews. Closing or switching the active asset draft drops that override so the saved-file preview is prepared again.
- Visible animation-frame texture dependencies register through `ResourceIndex` with the asset document identity and retire when no longer visible. The preview holds no authored history and never rewrites unknown fields.
- Added regressions for shared timing boundaries, loop behavior, over-limit frame and projected-data rejection without source mutation, unknown-field retention, and visible ResourceIndex dependency retirement.
- Verification: `cmake --build build --target platformator_editor_animation_test platformator_editor_resources_test platformator_editor_tabs_test platformator_editor -j8`; `ctest --test-dir build -R '^(platformator_editor_animation_test|platformator_editor_resources_test|platformator_editor_tabs_test|platformator_editor_accessibility_test|platformator_editor_sprite_region_test)$' --output-on-failure` (5/5 passed); `git diff --check` passed.
